# Git. Что это и каковы его возможности.  

__Git__ - это система контроля версий, которая позволяет отслеживать любые изменения в файлах, хранить их версии и оперативно возвращаться в любое сохраненное состояние.

## Работа с Git.  

Для эффективной работы с Git, вам необходимо установить соответствующую программу. Рекомендую использовать официальный сайт [Git-scm.com](https://git-scm.com). Для Windows  
можно просто скачать загрузочный файл и установить Git как обычную программу. В случае с MacOs и Linux для установки необходимо воспользоваться терминалом.

## Делимся проектами на GitHub.  
  
Для того, чтобы работать над проектом в команде, существует веб-платформа GitHub, основанная на системе контроля версий Git. Она позволяет разработчикам  хранить кодовые базы,
управлять версиями, совместно редактировать проекты, отслеживать ошибки и вести обсуждения между участниками команд.  

### Чтобы связать Git и GitHub, необходимо:  

* Создать репозиторий на [GitHub](https://github.com)  

* Добавить удаленный репозиторий по протоколу SSH под именем origin.  

* Проверить кореектное добавление командой  
"""
git remote -v
"""
* Занести все изменения, сделанные в локальном репозитории на GitHub командой
"""
git push -u origin master
"""  
- для **первого** раза и
"""
git push
"""  
- для последующих.
